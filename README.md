# MEP Works — 설비 엔지니어링 웹앱 쇼케이스

설비 실무자를 위한 계산 웹앱 모음을 소개하는 제품 사이트입니다.
https://choi-ilkwon.github.io/

## 구성

- `index.html` — 홈 (전체 제품 라인업)
- `apps/` — 제품별 소개 페이지 (위생배관 / 밸브 계통도 / HVAC 부하·용량 / 환기 덕트 / 소화설비 법규검토 / 스프링클러 / HVAC 시방서)
- `css/style.css`, `js/main.js` — 공통 스타일·스크립트

각 제품 페이지는 [불편함 → 해결 → 기능 → 라이브 데모(iframe)] 구조이며,
실제 앱은 각자의 저장소(GitHub Pages / Cloudflare Pages)에서 서비스됩니다.
